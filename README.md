## 👨‍💻 About Me

I'm a Computer Science graduate interested in the engineering behind reliable software: how services communicate, how data is stored and processed, and how applications remain maintainable as they grow.

My current focus is **backend software engineering**, while continuing to build the frontend skills needed to deliver complete products.

Areas I'm developing through hands-on projects:

- Backend development and REST API design
- Service architecture and asynchronous processing
- Relational database design and data access
- Real-time applications with WebSockets
- Authentication, authorization, and application security
- Caching and messaging with Redis
- Containerisation and cloud deployment fundamentals

I value understanding the architecture and trade-offs behind a solution, not just getting it to run.

## 🚀 Featured Projects

### [chat.zaAI](https://github.com/Bernard-Mokoana/chat.zaAI)
**Full-stack AI chat application | Python, FastAPI, Next.js, Redis, PostgreSQL**

An exploration of real-time AI application architecture. The system separates the WebSocket gateway from background workers and uses Redis Streams for message processing, with PostgreSQL supporting persistent data.

**Engineering concepts:** WebSockets, asynchronous workers, message queues, service separation, database migrations, and LLM API integration.

### [Real-Time Leaderboard](https://github.com/Bernard-Mokoana/Real_Time_Leaderboard)
**Real-time backend system | TypeScript, Node.js, Express, Socket.IO, Redis, PostgreSQL**

A real-time leaderboard application built around a TypeScript backend and event-driven communication. Redis and Socket.IO support real-time updates across connected clients.

**Engineering concepts:** REST APIs, WebSockets, Redis adapter, relational data, authentication, and backend service organisation.

### [Watchman](https://github.com/Bernard-Mokoana/Watchman)
**Fintech security concept | TypeScript, Node.js, Next.js, PostgreSQL, Redis**

A project exploring fraud detection and payment-routing concepts for digital transactions.

**Engineering concepts:** payment-system design, risk analysis, data processing, and backend architecture.

### [Encrypted File Transfer System](https://github.com/Bernard-Mokoana/Encrypted-File-Transfer-System)
**Networking and security | Java, TCP sockets, AES**

A client-server file-transfer project exploring network communication and encryption.

**Engineering concepts:** TCP sockets, client-server communication, and applied cryptography.
